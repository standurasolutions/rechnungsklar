Häufige Fragen

Ist die erzeugte XRechnung gültig?

Der Generator erzeugt XRechnung 3.0 in CII-Syntax. Jede Version wird vor der Veröffentlichung automatisch mit dem offiziellen KoSIT-Validator getestet.

Kann ich als Kleinunternehmer eine XRechnung erstellen?

Ja. Wählen Sie die Steuerkategorie „Kleinunternehmer (§ 19 UStG)“. Der Befreiungshinweis wird automatisch eingefügt.

Werden meine Daten gespeichert?

Nur auf Ihrem eigenen Gerät (im Browser-Speicher), damit Sie Ihre Firmendaten nicht jedes Mal neu eingeben müssen. Sie können sie jederzeit löschen.

Wie verschicke ich die XRechnung?

Einfach die heruntergeladene XML-Datei per E-Mail an die Rechnungsadresse Ihres Kunden senden. Bei Behörden nutzen Sie das jeweilige Rechnungseingangsportal.
